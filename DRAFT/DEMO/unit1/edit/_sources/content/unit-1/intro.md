# Unit 1: Learning from data

## Introduction to the unit

In this unit you will meet the central idea behind machine learning: instead of writing rules by hand, we let a program find them from examples. You will build the simplest possible learning system, a straight line fitted to data, and use it to understand ideas that carry through the whole programme: models, error, training and testing.

```{admonition} Unit learning outcomes
:class: note learning-objectives
By the end of this unit you will be able to:
- describe what a model is and what it means for it to *learn*
- measure how well a model fits data using an error metric
- explain why a model must be tested on data it has not seen
```

## How the unit is organised
