# Welcome to the demo module

This is a small, realistic example of a module built as a **Jupyter Book** and developed through **GitHub**. Everything you are reading started life as plain-text Markdown and notebook files in a repository, was reviewed through pull requests, and was published automatically.

```{admonition} How to navigate this module
:class: note
Use the footer navigation on each page to move on, or the side panel to jump to any unit or lesson.
```

## What you will find here

- **Unit 1** introduces the idea of learning from data, with a runnable notebook.
- **Unit 2** begins to look at classification and is still in development.

```{admonition} For the demo audience
:class: tip
Every page has a history. Find a sentence you like and ask: who wrote it, who reviewed it and when did it change? In a Word workflow that answer lives in someone's inbox. Here it lives in the repository.
```
