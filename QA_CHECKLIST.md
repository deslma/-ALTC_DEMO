# Review checklist

Automated checks (`scripts/qa_check.py` and the notebook build) cover alt text, heading order, placeholders and runnable notebooks. Reviewers focus on what only a person can judge.

## Pedagogy
- [ ] Learning outcomes are stated and the activities help students reach them
- [ ] There is a clear narrative from page to page and lesson to lesson
- [ ] Complex ideas are introduced step by step; pages are not overloaded
- [ ] Activities say how long they should take and what students need to do

## Language and layout
- [ ] Tone is consistent; sentences are short and clear
- [ ] No spelling or grammar errors
- [ ] Instructional text is consistent across lessons

## Accessibility
- [ ] Alt text is meaningful, not just present
- [ ] Information is never conveyed by colour alone
- [ ] Video has captions and a transcript

## Code and notebooks
- [ ] Notebooks run top to bottom without errors
- [ ] Code is explained, not just shown
- [ ] Any data used is available and permitted
